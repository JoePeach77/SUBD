# SUBD

Вариант 26

Автоматизация работы стационара в больнице
Описание Предметной области (ВНИМАНИЕ: список сущностей и их атрибутов определен ПРИМЕРНО, окончательное кол-во сущностей и их атрибутов нужно определить, исходя из раздела «Реализовать»)

Информация об отделениях стационара: название, кол-во коек, кол-во палат, заведующий

Пациенты: ФИО, паспорт, полис, телефон, адрес, дата рождения

Врачи: ФИО, специальность

Палаты: кол-во коек, м/ж, лечащий врач

Реализовать:
- Хранение информации о пролеченных больных (кто, когда, где лечился, диагноз, результат лечения)
- Получение информации о наличии мужских/женских мест в отделении;
- Получение отчетов о пролеченных больных (с названием диагноза, количестве дней лечения, результате лечения, рекомендациях) за заданный период;
